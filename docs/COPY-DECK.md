# Ferrari copy decks — plain text

Extracted verbatim from the three `.docx` files in [`../newwebsitepage/`](../newwebsitepage/),
so the copy is greppable and diffable in this repo. The `.docx` files remain the
source of truth; this is a convenience copy, not a rewrite.

**The three editions differ only in the Heritage module — the set of Atelier
compositions each retailer gets.** Everything else is identical boilerplate.
That difference is the single easiest thing to get wrong.

| retailer | compositions |
| --- | --- |
| Cauley Ferrari | Mountain Pass · The Mountains |
| Ferrari Las Vegas | Overlook · The Sands |
| Miller Motorcars | Byway · The Sands · The Great Plains |
